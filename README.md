# GitPilot AI

> **Turn GitHub Issues Into Intelligent Engineering Decisions.**

GitPilot AI is an intelligent GitHub repository management and issue-triage platform. It analyzes GitHub issues using **locally running machine-learning models**, determines issue type, priority, affected component, complexity, duplicate probability, and developer suitability, then provides explainable recommendations and optionally automates GitHub labels and assignments.

## Features
- Intelligent Issue Classification
- Priority Prediction
- Component Detection
- Complexity Prediction
- Duplicate Detection
- Developer Intelligence & Matching
- Explainable AI
- Repository Memory Engine
- Engineering Health Score
- Developer Workload Balancer
- AI Triage Timeline

## Architecture
- **Backend**: Python, FastAPI, PostgreSQL, scikit-learn
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
